# CMOS Differential Amplifier Design Using Cadence Virtuoso

A fully custom CMOS differential amplifier designed and simulated using **Cadence Virtuoso IC617** with **GPDK045 CMOS technology**.

## Project Overview

This project demonstrates the design flow of an analog CMOS circuit, including transistor-level schematic design, symbol creation, custom layout implementation, and circuit performance analysis using Cadence Spectre.

## Tools & Technology

- Cadence Virtuoso IC617
- Cadence Spectre Simulator
- GPDK045 CMOS Technology
- Full-Custom Analog IC Design Flow

## Design Features

- NMOS differential pair
- PMOS current mirror active load
- NMOS tail current source
- Single-ended output configuration

## Design Flow

1. Transistor-level schematic design
2. Symbol generation
3. Testbench development
4. Analog simulation:
   - Transient analysis
   - AC analysis
   - DC sweep analysis
5. Custom physical layout design

## Results

The designed differential amplifier was verified through Cadence Spectre simulations, showing proper differential amplification behavior and frequency response.
